# SWEEPER — GitHub Root Version

この版はGitHubのアップロード画面で**全部のファイルを同じ階層に入れても動く**ようにした簡易プロトタイプです。

## 操作
- 操作バーなし
- フィールドを直接タップ
- チップをタップして選択
- 敵をタップすると選択中チップを使用
- ATTACK / END TURN ボタンなし
- 敵マスはダブルタップでも反応
